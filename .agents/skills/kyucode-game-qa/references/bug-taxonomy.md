# Bug Taxonomy

## UI Errors
Visual discrepancies in user interface elements. Example: Buttons not responding.

## Collision Detection
Issues where objects do not collide as expected. Example: NPC walking through walls.

## Pathfinding
Problems with NPC navigation. Example: NPC stuck in an infinite loop.

## Rendering Issues
Errors in how elements are displayed. Example: Textures not loading properly.

## Minimap Discrepancies
Mismatches between onscreen elements and minimap indicators. Example: NPCs shown at wrong locations.

## Object Overlapping
When objects are visually overlapping in gameplay. Example: Characters intersecting in scenes.

## Other
Any bugs that do not fit into the categories above.
