# Unity QA Checklist

- **NavMesh:** Ensure properly configured for NPC navigation.
- **Collider:** Check collider boundaries for accuracy.
- **Rigidbody:** Verify correct settings for physics interactions.
- **UI Canvas:** Confirm hierarchy and visibility settings.
- **Sorting Layer:** Ensure correct layering for visual elements.
- **Animator:** Review animation settings for conflicts.
- **NPC Movement Script:** Analyze paths and settings for NPCs.
- **Minimap Sync:** Check minimap orientation and position accuracy.
