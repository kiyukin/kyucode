# kyucode Project Overview

The kyucode project is an AI Game QA Agent designed specifically for Unity games. This agent assists QA teams in identifying and resolving bugs through an analytical approach that incorporates game screen images and bug reports.

## Purpose as a Unity Game QA Agent
The primary goal of kyucode is to enhance the quality assurance process in game development by making it efficient and systematic. It analyzes gameplay screenshots and bug reports to identify potential issues and provide insights for fixing them.

## Why a QA Workbench Instead of a Chat UI?
Unlike simple chat interfaces, kyucode functions as a comprehensive QA workbench. This structure allows for deeper analysis and a more organized approach to bug detection and reporting, ensuring developers get actionable insights rather than just dialogue-based responses.

## Structure
- **Agent:** The overarching system that coordinates the analysis workflow.
- **Skill:** Specific capabilities that the agents utilize to perform tasks.
- **MCP (Main Controller Process):** The core that manages how agents interact and process tasks.
- **Extension:** Allows future functionalities to be added, enhancing kalucode’s abilities over time.
- **CLI (Command Line Interface):** Provides an easy way to interact with the kyucode system through command-line commands.

## Purpose of .agents/skills/kyucode-game-qa/SKILL.md
This file is essential for defining the specific skills and behaviors of the kyucode agent, ensuring it adheres to the Agent Skills standard. It allows for modular functionality, making future updates and improvements easier to implement.

## Mock Mode
The initial MVP operates in a mock mode, which allows the system to run without external API calls or live data from Unity. This design supports development without connectivity issues, enabling testing with local dummy data.

## Input Data Description
Input to the system includes: 
- **Bug Report:** A text file outlining observed bugs, including descriptions and potential implications.
- **Image Metadata:** JSON file containing metadata for screenshots taken from the game, summarizing the contents of each image.

## Output Files Description
The outputs generated by the system include:
- **result.json:** Contains structured analysis results detailing detected bugs, their severity, suggestions for fixes, and agent results.
- **report.md:** A Markdown formatted report summarizing the analysis in a human-readable format.
- **report.html:** An HTML report that presents the findings visually, suitable for business contexts.

## Execution Instructions
To run the application, use the command `npm start`, which will trigger the analysis process and generate output files.

## Current MVP Scope
The MVP does not include real-time code modifications; instead, it provides suggestions for fixing identified issues. The analysis is grounded on mock data, without integration into live Unity projects.

## Future Integrations with Unity Logs or Projects
There are plans for future enhancements to connect directly with Unity's logs and project settings, allowing for a more immediate and direct analysis of ongoing issues.

## Code Modification Limitations
The current MVP does not perform automatic code modifications. Instead, it focuses on suggesting improvements and potential directions based on the bug findings.
