# Commands

| Command Name             | 실행 명령                                        | 설명                                         | 사용 예시                                    |
|--------------------------|--------------------------------------------------|---------------------------------------------|----------------------------------------------|
| start-web-ui             | `npm run web`                                   | 웹 UI를 시작합니다.                        | `npm run web`                                |
| start-mcp-server         | `npm run mcp`                                   | MCP 서버를 시작합니다.                      | `npm run mcp`                                |
| run-vision-analysis      | `node src/mcp/server.js run_vision_analysis`   | Vision 분석을 실행합니다.                   | `node src/mcp/server.js run_vision_analysis` |
| list-screenshots        | `node src/mcp/server.js list_screenshots`      | 스크린샷 목록을 보여줍니다.                | `node src/mcp/server.js list_screenshots`   |
| read-latest-report       | `node src/mcp/server.js read_latest_report`     | 최신 보고서를 읽습니다.                     | `node src/mcp/server.js read_latest_report`  |
| open-latest-report       | `output/report_final.html`                       | 최신 보고서를 엽니다.                       | `open output/report_final.html`               |
